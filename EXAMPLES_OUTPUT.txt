ПРИКЛАД 5: Code Generation

Запит:
Write a JavaScript function that reverses a string. Code only, no explanations.

Параметри:
- Temperature: 0.3
- Max Tokens: 100

Відповідь:
```javascript
function reverseString(str) {
    return str.split("").reverse().join("");
}
```
