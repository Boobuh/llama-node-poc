# Приклади запитів та відповідей

Згенеровано через `npm run generate:examples` з provider **Ollama** (`ollama@0.6.3`), модель **llama3.2**. Для оновлення: `OLLAMA_MODEL=llama3.2 npm run generate:examples` → `EXAMPLES_OUTPUT.txt`.

## ПРИКЛАД 1: Слідування інструкціям

**Запит:**

```
Відповідай ТІЛЬКИ "ТАК" або "НІ". Чи вода мокра?
```

**Параметри:**

- Temperature: 0.1 (низька для точності)
- Max Tokens: 10

**Відповідь:**

```
Так, вода мокра.
```

**Примітка:** модель не дотримується суворого формату «ТАК»/«НІ» — це типова поведінка Llama-2-7B і аргумент на користь regression testing.

---

## ПРИКЛАД 2: Структурований вивід (JSON)

**Запит:**

```
Витягни ім'я та вік із тексту та поверни тільки валідний JSON:
"Мене звати Анна, мені виповнилося 29 минулого місяця."
```

**Параметри:**

- Temperature: 0.1 (для структурованого формату)
- Max Tokens: 50

**Відповідь:**

```json
{
  "name": "Anna",
  "age": 29
}
```

## ПРИКЛАД 5: Генерація коду

**Запит:**

```
Напиши JavaScript функцію, яка перевертає рядок. Тільки код, без пояснень.
```

**Параметри:**

- Temperature: 0.3 (баланс між креативністю та точністю)
- Max Tokens: 100

**Відповідь:**

```javascript
function flipString(str) {
  return str.split("").reverse().join("");
}
```

## ПРИКЛАД 7: Підсумкування тексту

**Запит:**

```
Підсумуй цей текст одним реченням:
Штучний інтелект (AI) — це інтелект, який демонструють машини,
на відміну від природного інтелекту, який демонструють люди та тварини.
Провідні підручники з AI визначають поле як вивчення 'інтелектуальних
агентів': будь-якого пристрою, який сприймає своє середовище і вживає
дій, які максимізують його шанси досягти своїх цілей.
```

**Параметри:**

- Temperature: 0.4
- Max Tokens: 80

**Відповідь:**

```
Artificial Intelligence (AI) is the intelligence demonstrated by machines, contrasted with the natural intelligence displayed by humans and other animals. Leading textbooks on AI define the field as the study of 'intelligent agents': any device that perceives its environment and takes actions that maximize its chances of achieving its goals.
```

## Технічні деталі

- **Модель:** Llama-2-7B-Chat (3.9GB, Q4_K_M quantization)
- **Provider:** Ollama (`ollama@0.6.3`), Node.js v22
- **Час генерації:** ~5–15 секунд на приклад
- **Локальна робота:** без API-ключів, повна приватність
- **Regression suite:** 27/31 тестів (87.1%) — `npm test`, 7 червня 2026

## Висновки

1. ⚠️ **Інструкції** — суворий формат не гарантований навіть при low temperature

3. ✅ **Код** — коректний синтаксис
4. ⚠️ **Контекст** — few-shot retention ненадійний
